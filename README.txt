SNOW PALS
1. Upload this folder to a Node.js hosting service (Render/Railway/etc.).
2. Build command: npm install
3. Start command: npm start
4. Open the resulting HTTPS link on both devices.
5. Dad taps Create Game and sends the room code to Aariz.
6. Aariz enters the code and taps Join.

For local testing on a computer:
npm install
npm start
Then open http://localhost:3000
